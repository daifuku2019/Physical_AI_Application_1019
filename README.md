物理シミュレータ **MuJoCo** 上に2自由度（2軸）の平面アームを自作し、強化学習アルゴリズム **PPO** で
「ランダムな位置に置かれた目標へ手先を到達させ、そこに留まる」動作を学習させました。
学習済みモデルの推論でアームを制御し、その様子を動画にしています。お手本となる動作データは使っていません。

- デモ動画（YouTube）：<YouTubeのURL>（等倍速）
- コード：`Physical_AI_Application.ipynb`（Google Colabで上から順に実行）

## 結果
学習時と異なる目標位置で、各100エピソードを評価しました。

| 評価項目 | 50万ステップ | 200万ステップ |
|---|---|---|
| 成功率（最終距離 < 2cm） | 7.0 % | **100.0 %** |
| 最終距離の平均 | 91.5 mm | **4.7 mm** |
| 最終距離の最大 | 277.9 mm | 12.5 mm |
| 2cm以内に初めて入るまでの平均時間 | 0.99 s（到達した7回のみ） | 1.13 s（全100回） |
| 平均エピソード報酬（学習開始時 → 終了時） | −94.0 → −32.1 | −81.8 → −14.8 |
| 学習時間（Colab CPU） | 約2.8 分 | 約10.6 分 |

50万ステップでは学習曲線がまだ上昇中で、学習が収束していませんでした。
学習量を200万ステップに増やすと、約75万ステップ以降で収束し、成功率は100%になりました。

## 使用技術
| 役割 | ツール |
|---|---|
| 物理シミュレータ | MuJoCo |
| 強化学習環境 | Gymnasium（自作の環境クラス `Arm2Env`） |
| 強化学習 | Stable-Baselines3 の PPO（MlpPolicy：64ユニット×2層） |
| 可視化・動画 | matplotlib、imageio |
| 実行環境 | Google Colab（CPUランタイム） |

## タスク設計
| 項目 | 内容 |
|---|---|
| ロボット | 長さ0.2mのリンク2本、ヒンジ関節2つ（関節2は±150°）。重力なしの平面運動 |
| タスク | 毎エピソード、目標を中心から0.1〜0.38mのランダムな位置に配置 |
| 観測（10次元） | 関節角度のcos・sin（4）、関節角速度（2）、目標位置（2）、手先と目標のズレ（2） |
| 行動（2次元） | 2つの関節モータへのトルク指令（−1〜+1） |
| 報酬 | −（手先と目標の距離）− 0.01 ×（トルク指令の二乗和） |
| エピソード長 | 200ステップ（4秒） |
| 成功の定義 | エピソード終了時の手先と目標の距離が2cm未満 |
| 学習条件 | 総ステップ数 2,000,000、並列環境数 8、n_steps 1024、batch_size 256 |

## 工夫した点
- **報酬設計**：距離に加えてトルクにも小さなペナルティを課し、無駄な力を使わず目標に留まる動作を促しました。
- **観測設計**：関節角度をcos・sinで表し、359°と1°のような角度の不連続をなくしました。
- **汎化**：目標位置を毎回ランダムにし、評価には学習時と異なる乱数シードを使いました。
- **実行環境への対応**：ColabでMuJoCoのOpenGL描画が原因のクラッシュが起きたため、物理計算はMuJoCoのまま、可視化だけをmatplotlibで行う構成にしました。GPUの有無に関係なく動作します。
